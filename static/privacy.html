Политика конфиденциальности

Дата последнего обновления: 13 сентября 2026 года

1. Общие положения

Настоящая Политика конфиденциальности определяет порядок обработки и защиты персональных данных пользователей (далее — «Пользователи») на сайте «FoodDrop» (далее — «Сайт» или «Сервис»). Оператором персональных данных является ИП [ФИО] (далее — «Оператор»).

Используя Сайт, Пользователь выражает своё согласие с настоящей Политикой конфиденциальности. Если Пользователь не согласен с условиями данной Политики, он должен прекратить использование Сайта.

2. Собираемые персональные данные

Мы собираем следующие персональные данные Пользователей:

  • ФИО — имя и фамилия для оформления заказа
  • Телефон — номер телефона для связи и подтверждения заказа
  • Адрес доставки — адрес для доставки заказа (при выборе доставки)
  • Состав заказа — список выбранных блюд и их количество

3. Цели обработки персональных данных

Персональные данные обрабатываются в следующих целях:

  • Обработка и выполнение заказов Пользователей
  • Связь с Пользователем для уточнения деталей заказа
  • Информирование о статусе заказа
  • Улучшение качества обслуживания

4. Правовое основание обработки

Обработка персональных данных осуществляется на основании:

  • Статьи 24 Конституции Российской Федерации
  • Федерального закона № 152-ФЗ «О персональных данных» от 27.07.2006
  • Согласия Пользователя на обработку персональных данных

5. Хранение персональных данных

Персональные данные хранятся:

  • На сервере Оператора — в защищённой базе данных SQLite
  • В localStorage браузера Пользователя — для сохранения корзины и заказов при отсутствии соединения с сервером (ключи: imperiya_orders, imperiya_admin_token)

Срок хранения персональных данных: не более 3 лет с момента последнего заказа, после чего данные удаляются или анонимизируются.

6. Передача персональных данных третьим лицам

Мы не передаём персональные данные третьим лицам, за исключением случаев:

  • По требованию органов правоохранительных и судебных органов
  • Для выполнения обязательств перед Пользователем (курьерская служба для доставки)
  • С согласия Пользователя

7. Защита персональных данных

Мы принимаем необходимые организационные и технические меры для защиты персональных данных:

  • Шифрование данных при передаче (HTTPS)
  • Ограниченный доступ к данным персонала
  • Регулярное обновление программного обеспечения
  • Использование защищённых протоколов авторизации (JWT)

8. Права Пользователя

Пользователь имеет право:

  • Получить информацию об обработке своих персональных данных
  • Требовать уточнения или удаления своих персональных данных
  • Отозвать согласие на обработку персональных данных
  • Подать жалобу в Роскомнадзор или суд

9. Изменение Политики

Мы вправе изменять настоящую Политику конфиденциальности. Новая версия вступает в силу с момента её размещения на Сайте. Рекомендуем регулярно проверять актуальность Политики.
